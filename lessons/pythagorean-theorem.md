# The Pythagorean theorem
keywords: pythagoras pythagorean theorem triangle right hypotenuse
Source: written by the candidate for this prototype (original text).

Key idea: in a right triangle with legs a and b and hypotenuse c (the side opposite the right angle), a² + b² = c². The squares built on the two legs together have the same area as the square built on the hypotenuse.
It only holds for right triangles. Converse: if a² + b² = c² then the triangle is right-angled.
Worked example: legs 6 and 8: c² = 36 + 64 = 100, so c = 10. If the hypotenuse is 13 and one leg is 5: b² = 169 − 25 = 144, b = 12.
Common errors: using the formula on non-right triangles; treating a leg as the hypotenuse; writing c = a + b; forgetting the square root at the end.
