# Solving linear equations
keywords: linear equation equations solve solving algebra unknown balance variable
Source: written by the candidate for this prototype (original text).

Key idea: an equation is a balance. Whatever you do to one side you must do to the other, so the two sides stay equal and the solution never changes.
Why "move it to the other side and change the sign" works: it is shorthand for subtracting (or adding) the same number on both sides. 3x + 5 = 20: subtract 5 from both sides, 3x = 15; divide both sides by 3, x = 5. Check by substitution: 3·5 + 5 = 20.
Common errors: applying an operation to only one term; forgetting to divide every term; thinking the equals sign means "the answer is next" instead of "both sides have the same value"; sign errors with negatives.
